# Building "@TITLE@" (@PLATFORM@)

This folder was generated by **gase-recomp**. It contains:

| path | what |
|------|------|
| `generated/` | the 68000 code of the ROM, translated to C |
| `runtime/` | the portable runtime: CPU glue, memory map, VDP (video), PSG (sound), pads |
| `assets/rom.bin` | your ROM: graphics, sound and data are still read from it at runtime |
| `CMakeLists.txt` | one build script for every platform |

## Desktop (Linux, macOS, Windows)

Install SDL2 (`apt install libsdl2-dev`, `brew install sdl2`, or vcpkg on Windows), then:

```sh
cmake -S . -B out
cmake --build out --config Release
./out/@ID@            # rom.bin is copied next to the executable
```

Keys: arrows, Z/X/C = A/B/C, Enter = Start, Esc = quit. Gamepads work out of the box.

## Headless (tests, CI)

```sh
cmake -S . -B out-headless -DGASE_HEADLESS=ON && cmake --build out-headless
./out-headless/game_headless assets/rom.bin 120 frame.ppm
```

## Android

Requirements: Android Studio (or the SDK + NDK + Gradle 8).

```sh
./scripts/fetch_sdl2.sh          # SDL2 sources in third_party/SDL2
```

Open the `android/` folder in Android Studio and press Run. The ROM is
packaged in the APK as an asset. On-screen touch controls are drawn over
the game; Bluetooth gamepads work too.

## iOS

Requirements: macOS with Xcode and CMake.

```sh
./scripts/fetch_sdl2.sh
./ios/generate_xcode.sh          # creates ios/build/@ID@.xcodeproj
open ios/build/@ID@.xcodeproj
```

Pick your development team in *Signing & Capabilities*, then Run.

## "No recompiled code for $XXXXXX"

Static analysis can't see every target of `jmp (a0)` or jump tables. When the
game reaches such an address, the runtime appends it to `gase_missing.txt`
and stops. Copy that file into this folder and run the same
`python -m gase recomp ...` command again: the address becomes a new
function. Repeat until the game plays through. This is the **coverage
feedback loop** described in the making-of.
